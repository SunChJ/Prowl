# Prowl

## Register

product

## Users

Developers on macOS who orchestrate multiple AI coding agents across repositories, worktrees, tabs, and panes. They need to monitor progress, direct attention, and move between concurrent tasks without losing terminal context.

## Product Purpose

Prowl is a native macOS command center for running coding agents in parallel. It makes agent state, terminal sessions, and git worktrees legible and controllable at a glance. Success means users can identify what needs attention and act on it with minimal navigation or context switching.

## Brand Personality

Focused, confident, and quietly playful. Prowl should feel fast and distinctly native while keeping its cat-inspired identity subtle enough that the tool disappears into serious daily work.

## Anti-references

- Generic Electron-style terminal dashboards that feel detached from macOS.
- Decorative agent or SaaS chrome that competes with live work.
- Duplicate labels and controls that repeat context already visible elsewhere.
- Novel interaction patterns where standard macOS controls are clearer.
- Layout shifts, noisy status decoration, or color-only state communication.

## Design Principles

- Put the next agent needing attention within a glance or one action.
- Preserve terminal context while users orchestrate work across branches and panes.
- Prefer native macOS behavior, controls, materials, and keyboard conventions.
- Keep dense workflows calm through stable layout and purposeful hierarchy.
- Earn every persistent toolbar element through frequent, actionable value.

## Accessibility & Inclusion

Use Dynamic Type, semantic labels, system colors, and sufficient contrast. Every action must remain keyboard-accessible and expose its shortcut in help text where applicable. Status must not rely on color alone, and motion must respect reduced-motion preferences.
